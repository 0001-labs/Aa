# Inter

`Inter-Arrows.woff2` is Inter Regular 4.1, cut down to its arrows (U+2190–21FF, U+27F0–27FF, U+2900–297F, U+2B00–2BFF). It is loaded as "Inter Arrows" and leads every typeface token, so an arrow is drawn in Inter whatever the text around it is set in.
