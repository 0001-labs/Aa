# Aa's fonts

## Aa Mono

`aa-mono.woff2` is Iosevka Regular 33.3.6, cut down to the characters code uses (Latin, punctuation, arrows, maths, box drawing), and loaded as "Aa Mono".

## Inter Arrows

`inter-arrows.woff2` is Inter Regular 4.1, cut down to its arrows (U+2190–21FF, U+27F0–27FF, U+2900–297F, U+2B00–2BFF), and loaded as "Inter Arrows" first in every font Aa sets, so arrows are always Inter.
